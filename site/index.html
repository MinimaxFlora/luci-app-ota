通过 OTA 升级（推荐）

固件内置 luci-app-ota：在 LuCI 的「系统 → 在线升级」里检查、下载并安装，无需电脑。

1

确认更新源

插件默认已指向本页的索引地址，一般无需修改。若你手动装过插件，可以在「在线升级 → 配置」里填写：

ota.json
2

检查更新

打开「系统 → 在线升级」，点击「检查更新」，会显示新版本的构建时间与更新日志。

ota check
3

下载并安装

下载会在后台进行，完成后自动校验 SHA256 并预检镜像是否属于本机，然后调用 sysupgrade 写入。默认保留当前配置。

ota download && ota apply --keep 1

升级过程中设备会重启，耗时几分钟，请不要断电。安装后配置文件保持不变，管理地址与 WiFi 也不变。

更新日志

每次构建都会记录在案。

常见问题

怎么知道该下载哪个镜像？

以路由器为例，型号是 Ruijie RG-X60 就选对应那张卡片；x86 设备分传统 BIOS 与 UEFI 两种，机器以 UEFI 启动就选 UEFI 镜像，否则选 BIOS 镜像。选错会导致无法启动。

OTA 和手动刷机有什么区别？

OTA 只替换系统分区并保留配置，速度更快、更不容易出错；手动刷机适合首次安装或系统已经无法启动的情况。

为什么要提供 SHA256？

插件在下载完成后会强制校验 SHA256，值不匹配就丢弃镜像。你也可以手动核对：下载后计算文件哈希，与本页显示的值比较。

更新日志里的版本号是什么？

ZeroWrt 用构建日期作为版本号（例如 20261020 表示 2026-10-20 的构建），排序与比较都以镜像内的构建时间戳为准。

页面多久更新一次？

每次构建发布后自动更新一次，数据直接来自固件仓库的发布流程，无需人工维护。
